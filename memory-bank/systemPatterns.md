# System Patterns

## Architecture Patterns
- Component-based React architecture
- State management with Zustand stores
- OPFS for offline-first file storage
- Google Drive API integration for media sync

## Component Structure
- LocationSelection: Gym location picker
- Slideshow: Media display component
- MediaSync: Google Drive integration
- OPFSManager: File storage operations

## State Management
- Location store: Current selected gym
- Media store: Available media files
- Sync store: Download/sync status

## File Organization
- Shared folder: Common content for all locations
- Location folders: Specific content per gym
- OPFS structure: Mirrors Google Drive hierarchy
